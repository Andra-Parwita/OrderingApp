Visual directions · batch 1

Draft 1, 2026-10-07 · static mock-up, not a build source

Purpose: pick one visual direction (colour only) for the whole app before any UI is built. Both directions share the same layout, spacing, type scale and radii from src/theme/tokens.ts; only the colour tokens differ. Direction A is the current theme exactly. Direction B is a proposal and exists on this page only.

How to compare: look at the same four frames in each direction (Customer menu light, Seller orders light, then the same two in dark). Check: does the one accent colour feel calm, do the status pills read at a glance, is the list dense but not tiring, and does the focus ring show clearly (each frame shows one control in its keyboard-focus state). Then read the token tables: every text and UI pair passes WCAG AA in both modes. Reply with A or B (or "A with B's surface").

  • Accent is used only on the primary action, the selected language pill, the focus ring and the selected-tab line.
  • Status pills are muted tints and always carry text. Status tints are proposed here for both directions (the current theme has no status tokens yet).
  • No boxed cards: 1px hairlines, spacing and slight surface tints only.

Comparison

A · Sage

  • Feel: cool, calm and clinical-fresh; green reads as "go" and "fresh food", very quiet next to the grey-beige neutrals.
  • Strengths: already built into the tokens (no rework); highest contrast headroom for the accent; green sits naturally with food and avoids any "error" connotation.
  • Risks: accent and the "Ready" status tint are both green, so the primary button and a positive status can look related; can feel generic or slightly cold for a home cook.

B · Clay

  • Feel: warm, homely and appetising; terracotta and warm neutrals suggest kitchen, clay pots and spices while staying muted.
  • Strengths: a distinct identity from the status colours (green Ready, amber Ordered, slate Confirmed all stay clearly separate); the warmth suits a personal seller brand; passes AA with room (lowest text ratio 5.12).
  • Risks: terracotta sits near red, so it needs discipline (accent never on errors or Cancelled); less contrast headroom on accent-on-surface than A's dark mode; needs a change to themes.ts and an owner OK.
