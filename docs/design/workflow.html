Weekly order workflow

Three actors over one week. The server is the Cloudflare Worker (D1 for data, a Durable Object for the seller's live list, Web Push for notifications). Draft for review, 2026-10-07.

In the app (HTTPS to the server) WhatsApp (never touches the server)
  • Private data stays off the server (D-007): phone numbers and delivery addresses travel only on the WhatsApp lines and live on the seller's own device.
  • Unconfirmed at the cut-off (D-009): nothing happens automatically; the seller's list flags them.
  • Every notification also appears in the order page's in-app inbox.
